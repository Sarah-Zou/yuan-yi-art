# Brand Images

Hero and supporting imagery for the brand (not individual products).

Suggested files:

- `hero.jpg` — main home-page hero photograph
- `portrait-grandmother.jpg` — optional archival portrait for the About page
- `portrait-mother.jpg` — optional portrait
- `portrait-founder.jpg` — optional portrait

Once added, reference them in the relevant pages (e.g. `app/page.tsx`) by replacing the placeholder tile with an `<img>` tag pointing to `/images/brand/hero.jpg`.
